macOS default input | system route

Choosing a device does not change the route until you apply it.

Apply changes the macOS system-wide input. Ableton may use its own device selection; this does not change Scarlett input mode or monitor mixes.

macOS default output | system route

Choosing a device does not change the route until you apply it.

Apply changes the macOS system-wide output. Ableton may use its own device selection; this does not change Scarlett monitor mixes.

Scarlett sample rate | hardware control

Current rate and supported rates are read from CoreAudio.

Applying a rate changes the Scarlett device for all apps and can interrupt active audio streams. Save work and stop audio before applying.

Scarlett clock source | hardware control

Current and supported clock sources are read from CoreAudio.

Applying a clock source can interrupt active audio. External S/PDIF or ADAT sync requires a valid connected clock source.

Input 1-2 mode | hardware control

Mode not read. Set buttons change the selected hardware input and verify by reading it back.

Only Inputs 1-2 are enabled, matching the original Scarlett 18i8 Line/Inst controls. This does not change gain level or routing.

Preamp PAD | Inputs 1-4

Read the current state before changing PAD.

PAD attenuates the analog preamp signal. Applying it can reduce the input level and affect all apps using that input.

Input gain | read-only USB query

Not queried. This button sends one GET_CUR read and does not change the gain.

The returned byte is still an undecoded protocol value, not dB. Connect an instrument to the selected input when you are ready to test.
